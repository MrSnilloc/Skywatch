# Sky Watch — Android app

This folder wraps the Sky Watch web app (the folder above) into a real Android app with Capacitor.
The app can read data that browsers block for websites (live planes) and can later send notifications.

## One-time setup (Windows)
1. Install **Android Studio** from https://developer.android.com/studio (all defaults).
2. Open Android Studio once and finish the **Setup Wizard** (choose *Standard*). It downloads the Android SDK.
   You can close Android Studio afterwards — you don't need to open this project in it.

## Build the app
Double-click **`Build Android App.bat`** in the main Skywatch folder.
The first build downloads build tools (5–10 minutes). When it finishes, File Explorer opens with
**`android-app\SkyWatch.apk`** selected.

## Install it on the phone
Copy `SkyWatch.apk` to the phone (USB cable, Google Drive, or email it to yourself), tap it, and allow
"install unknown apps" for the app you opened it with when Android asks. Rebuilt versions install over the old one.

## Layout
| Path | What it is |
|---|---|
| `capacitor.config.json` | App id, name, native HTTP on, dark system bars |
| `android/` | The Android Studio project (generated by Capacitor; permissions in `app/src/main/AndroidManifest.xml`) |
| `capacitor-android/` | Capacitor's Android library, kept here so no Node.js is needed on Windows |
| `copy-web.sh`, `sync.sh`, `package.json` | Used on Claude's side to regenerate the project after big changes |
